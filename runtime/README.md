# Inbox Triage Agent: /runtime

**Agent:** Inbox Triage Agent for a small local business (e.g., a campus-area bike repair shop)
**Owner:** Solo build

## Business problem
A 3-person bike repair shop gets 40-60 customer emails a week (repair quotes, pickup status, hours, warranty questions). The owner spends ~6 hours/week sorting and replying, and quote requests sometimes sit for days, losing customers.

**Agent goal:** Read new emails, classify them, draft a reply for routine ones, log every request to a database, and flag quote requests for the owner. Nothing is sent without owner approval.

**Level of automation:** Draft-and-approve (human in the loop for all outbound messages).
